# Portfolio

Personal portfolio website built to showcase projects, skills, experience, and contact details in a polished single-page experience.

## Tech Stack

- React
- TypeScript
- Vite
- CSS

## Features

- Modern portfolio layout with dedicated sections for home, skills, experience, projects, about, and contact
- Animated transitions and interactive UI elements
- Project showcase with live demo and repository links
- Responsive structure for a smooth browsing experience

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
